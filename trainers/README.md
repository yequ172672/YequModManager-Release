# 可选 CT 修改表目录

本目录为夜阙 ModManager 的游戏修改拓展提供按需下载数据，不随管理器全部内置。

本轮检索覆盖 260 个当前预设；245 个预设有表文件或作者页面候选。托管 23 张保留原始字节的 CT；另有 484 个仅来源链接的条目。

- [目录](catalog.json)：选择游戏和条目，托管下载固定到文件发布提交并校验 SHA-256。
- [覆盖记录](coverage.json)：包含未找到来源的预设。
- [来源与许可](acquisition.json)：冻结的上游仓库提交。
- [静态检查](preflight.json)：只表示当前解析器的语法子集，不能证明地址、脚本或游戏效果。

每张托管表与原许可证、SOURCE.json 同目录。未明确允许再分发的来源保留作者页面，不镜像其文件；下载表时须同时保留对应许可证和来源信息。

当前自研引擎不依赖 CE，支持数值/指针链、AOB 和常用汇编补丁子集；Lua 与 CE 专用指令尚不支持。表中的所有功能都可能随游戏版本失效，部分托管表当前静态可用项为 0，保留它们只作为作者资源。所有表均未经过本项目的实际游戏验收。

## 原作者直链与 GitHub 跳转

[打开下载入口](https://yequ172672.github.io/YequModManager-Release/)。新增 103 个已验证 CT 直链、2 个作者压缩包，以及 102 个待验证附件链接；277 个暂保留来源页面。

未镜像的文件由原作者站点直接提供。静态跳转页不是文件代理；管理器只自动导入已校验的 CT，压缩包、登录要求和限流情况交由浏览器处理。验证状态详见 [redirects.json](redirects.json)。
